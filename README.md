# Skills

Most of the agent skills I use every day: committing, pulling and pushing, investigating failures, writing prose and code comments, and setting up repositories for agents.

Every skill follows the [Agent Skills](https://agentskills.io) format, so it works in Claude Code, Codex, Cursor, Gemini CLI, OpenCode and any other agent that reads `SKILL.md`.

## Install

Pick from the list:

```sh
npx skills add marvinjwendt/skills
```

Or install one skill for every project:

```sh
npx skills add marvinjwendt/skills -s unslop -g
```

`npx skills add marvinjwendt/skills --list` shows what is available. Browse [`skills/`](skills) to read them first.
