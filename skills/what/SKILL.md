# What

The last message did not land. Explain it again in chat. Do not edit files, do not redo the work, and do not open with an apology for the first version.

- Run the `unslop` skill over the rewrite. Plain words, short sentences, nothing padded.
- Add detail instead of cutting it. The first version was unclear, not too long. Name what it assumed: the term used without a definition, the step treated as obvious, the reasoning behind the decision.
- Say what it means in practice: what changed, what it affects, what to do with it.
- Length follows the explanation. Simple means clear, not shorter.

Each `/what` in a row goes one level past the one before it: more detail, smaller steps, more basic terms, a concrete example where the abstract version failed. Restating the previous rewrite in different words is the one thing that does not count.
